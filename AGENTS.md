# AEIOU — Hack-Nation 7 (2026)

## Rules

- **Stay in scope.** Do only what the user asked. No unrequested refactors, features, files, dependencies, or "while I'm here" cleanups. If something else looks worth doing, mention it — don't do it.
- **Commits follow Angular style** (see `CONTRIBUTING.md`). Use the `commit` skill.
  - Subject line only. Add a body only when the change genuinely can't be understood without one.
  - **No co-authoring.** Never add `Co-Authored-By:` trailers or any other attribution lines to commits or PRs.
- **Deferred work** is recorded in `docs/homework.md`. Check it before starting work in an area; add to it whenever you leave something for later.
- **Privacy & compliance:** read `docs/compliance.md` before any frontend, backend or end-to-end task. Where GDPR and California rules differ, the stricter one wins.
